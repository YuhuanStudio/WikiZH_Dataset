# legacy

改版前的實作，保留備查，**不參與現行流程**。

| 檔案 | 原本的角色 | 為什麼被取代 |
|------|-----------|-------------|
| `md_to_json.py` | 把 `markdown/` 下的每篇 `.md` 轉成段落級 JSON | 改成文檔級 Parquet（`md_to_dataset.py`）。段落級會切斷長距離依賴，且其 `normalize_text` 會刪掉正文——`公式為E = mc²` 變成 `公式為`、`AT&T` 變成 `ATT`、含「決賽」的整句消失 |
| `image_extractor_v1.py` | 逐行掃描 dump 抓 `[[File:…]]` | 只認一種前綴、不看 `<gallery>`、抓不到跨行語法，漏掉約五分之一的圖片；圖說另用一套較弱的清理邏輯（10.8% 帶著未展開的模板） |

現行對應模組見上層 `README.md` 的「模組」一節。
